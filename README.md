# Tetris Game

Recreate game Tetris klasik menggunakan Python dan Pygame.

## Fitur
- Gameplay Tetris klasik dengan kontrol sederhana
- Sistem penilaian yang meningkat seiring baris yang diselesaikan
- Tingkat kesulitan progresif seiring peningkatan level
- Tampilan grid yang jelas dengan warna yang berbeda untuk setiap tetromino

## Teknologi yang Digunakan
- Python 3.x
- Pygame Library

## ⌨️ Kontrol
| Tombol         | Aksi                    |
|----------------|-------------------------|
| ⬅️ Kiri        | Geser ke kiri           |
| ➡️ Kanan       | Geser ke kanan          |
| ⬇️ Bawah       | Geser ke bawah          |
| ⬆️ Atas        | Rotasi block            |
| SPACE          | Instant drop (langsung jatuh) |
